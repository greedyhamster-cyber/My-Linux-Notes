# My-Linux-Notes
第一天：linux基础命令实战
今天成功登录了linux的环境，学了三个基础命令
1.pwd:看当前在哪个目录
2.ls:看当下目录有什么文件
3.cd:切换目录。cd ..：返回上一级；cd -:返回上一次目录；单敲cd：回家
4.新建文件夹：mkdir -p 文件夹名字，可以一次弹出多个文件夹
5.echo "____"表示printf的意思，感觉很像
6.echo "___" > ______.txt表示把这个东西装到里面，
7.echo"_______">>_______.txt表示把下一句在不删掉前文的基础上装到里面
8.cat hello.txt表示看看里面在干啥，会打印出来里面的内容
9.head heelo.txt表示显示文件的前10行
10.tail -2 hello.txt表示只看文件的最后两行
11.stat hello.txt表示看到该文件的一堆属性
12.stat dir1只是装东西的目录
13.du -h:以人类可读的方式显示当下文件的大小
14.du -h --max-depth=1:只查看当前目录下一级的文件大小，不无限向下钻取
15.cp 源文件 目标路径：复制文件
16.cp -r 源目录 目标目录：复制文件夹（—r的意思是递归，把整个文件夹复制过去）
17.mv 原名字 新名字：mv hello.txt hi.txt
18.mv 文件 目标路径:把文件剪切到另外一个目录中
19.md5sum 文件名：看指纹
20.rm 删除文件
21.rm -i:删除前会问你，稍微安全点
22.rm -rf 目录名：直接全部删掉，问都不问，慎用啊啊啊
23.rmdir 目录名：只可以用来删除空目录
24.Tab:敲一半忘了，用这个让系统帮你补全
